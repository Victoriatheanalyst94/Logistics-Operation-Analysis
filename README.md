# Logistics-Operation-Analysis


#Project Overview---This project analyzes logistics operations to evaluate fleet performance, maintenance activities, fuel consumption, deliveries and operational efficiency. The analysis identifies trends affecting transportation performance and provides recommendations for improving logistics operations.



#Business problem---Logistics companies manage large volumes of deliveries, vehicles and maintenance records Without proper analysis, organizations may experience increased operating cost, delayed deliveries and poor fleet(vehicles) utilization.


#Objectives---(1)Analyze fleet utilization (2)Monitor delivery performance (3)Evaluate maintenance cost (4)Analyze fuel expenses (5)Measure driver performance (6)Improve operational efficiency


#Tools Used---SQL server, Excel, Power BI


#Data Cleaning---(1)Removed duplicates (2) Checked missing values (3)Changed abbreviations to full texts (4) Joined multiple related tables.


#Analysis---(1)Total trips (2) Total loads delivered (3) Maintenance cost (4) Fuel purchases (5)Averagbe trip distance (6) Driver performance.
